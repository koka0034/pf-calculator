Как пользоваться

Назначение

Программа для инвентаризации: бар, кухня, посуда, карты/форма и другое имущество. Работает и в одиночку, и в команде — совместная инвентаризация ведётся по коду сессии.

Изоляция данных

Все данные на сервере привязаны к коду сессии. Подсчёты разных заведений не пересекаются — даже если совпали склад и дата. Без активной сессии выгрузка на сервер недоступна (подсчёт при этом продолжает работать локально).

Сохранение данных

Офлайн. Весь подсчёт хранится локально в памяти браузера, есть история сохранённых подсчётов на «Главной». Онлайн. Связь нужна только для сессии: создать, войти, выгрузить и принять подсчёты.

Начало (инициатор)

  • На «Главной» выберите склад (Бар/Кухня/Посуда/Карты/Форма/Имущество) — по нему подтянется список товаров.
  • При необходимости обновите список: кнопка «Структура товаров (бланк)», файл только .xlsx (если .xls — пересохраните в Excel через «Сохранить как»).
  • Нажмите «Создать сессию» — появится код. Передайте его тем, кто считает (список товаров уйдёт им автоматически).

Подсчёт (все участники)

  • Введите код → «Войти в сессию». Склад и список товаров подставятся сами, откроется вкладка «Товары».
  • Посчитайте свою зону на вкладках «Товары» и «ПФ».
  • Нажмите «Выгрузить мой подсчёт» — данные уйдут инициатору, поля очистятся.

Сведение

  • Когда все выгрузили — «Принять результаты с сервера»: подсчёты суммируются и сервер очищается.
  • Проверьте «Расхождения (факт − расчёт)»: минус — красным (нехватка), плюс — зелёным (излишек).
  • «Заполнить и скачать» впишет остатки в шаблон бланка (файл сохранится как имя-шаблона_заполненный.xlsx).

Индивидуальная инвентаризация

Один человек — сессия не нужна: выберите склад, посчитайте, «Заполнить и скачать».

Важно про сверку. Для расхождений нужен свежий отчёт «остатки на складах». Финальную сверку делайте перед отправкой, когда товаровед провёл все приходы, перемещения и списания.

Кнопки очистки

«Очистить только товары» (вкладка Товары) и «Очистить только ПФ» (вкладка ПФ) сбрасывают свою вкладку. «Очистить весь подсчёт» («Главная») сбрасывает и товары, и ПФ. Все — с подтверждением в два нажатия.

Подсчёт работает офлайн; связь нужна только для выгрузки и приёма результатов.
