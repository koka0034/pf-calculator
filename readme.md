# Калькулятор ПФ → товары

Калькулятор разборки настоек (полуфабрикатов, ПФ) в товары по ТТК.
Один файл, работает офлайн, открывается на телефоне и компьютере
(iPhone / Android / Mac / Windows).

## Что внутри

- `index.html` — сам калькулятор. 16 настоек, норма «товар на 1 л ПФ»,
  авто-пересчёт итога по товарам, печать отчёта, сохранение подсчётов по дате.
- `icon.png` — иконка для главного экрана (лежит рядом с `index.html`).

Оба файла должны лежать в одной папке (репозитории) — `index.html` ссылается
на `icon.png`.

## Как выложить на GitHub Pages (один раз)

1. Зарегистрируйся на [github.com](https://github.com) (если ещё нет аккаунта).
2. Создай репозиторий: кнопка **New repository** → имя, например `pf-calculator`,
   тип **Public** → Create repository.
3. Включи Pages: в репозитории **Settings → Pages** → Source: **Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Загрузи файлы: в репозитории **Add file → Upload files** → перетащи
   `index.html` и `icon.png` → **Commit changes**.
5. Через 1–2 минуты сайт заработает по адресу
   `https://<твоё-имя>.github.io/<имя-репозитория>/`.

На iPhone: открой этот адрес в Safari → «Поделиться» → **«На экран “Домой”»**.

## Как обновлять калькулятор

**Самый простой способ (через сайт GitHub):**
открой `index.html` в репозитории → карандаш **Edit** → вставь новый код →
**Commit changes**. Или **Upload files** и замени файл целиком.

**Через командную строку** (когда правки вносит тот, у кого есть доступ):

```bash
git add index.html icon.png
git commit -m "обновление калькулятора"
git push origin main
```

## Первый запуск через командную строку

Если репозиторий ещё не связан с GitHub:

```bash
git init
git add .
git commit -m "первая версия"
git branch -M main
git remote add origin https://github.com/<имя>/<репозиторий>.git
git push -u origin main
```

## Где лежат рецепты

Все рецепты и нормы встроены прямо в `index.html` — это массив `RECIPES`.
Чтобы добавить настойку или поменять норму, редактируется именно он.
Формат записи: название, выход в литрах и список ингредиентов
(товар, единица, норма на 1 л).
